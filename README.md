# Cyber Sentinel Academy

A professional, single-file cybersecurity learning landing page.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/root`, then Save.

The uploaded logo is embedded directly inside `index.html`, so there is no separate image dependency.
